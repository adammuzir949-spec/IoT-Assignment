# Seri Iskandar Weather Monitor

TFB2093 Internet-of-Things group project. Collects hourly weather observations
and forecasts for Seri Iskandar from the Open-Meteo API, stores them in Supabase,
measures forecast accuracy, and displays results on a Streamlit dashboard.
